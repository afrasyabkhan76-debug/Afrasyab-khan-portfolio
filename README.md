## Features

- Responsive layout for phones, tablets and desktops
- Light and dark theme, and the choice is remembered
- Typing effect, scroll animations and hover effects
- Scroll progress bar and a back-to-top button
- Mobile menu, and the menu highlights the section you are in
- Copy-email button in the contact section
- Animations switch off for visitors who prefer reduced motion

## Built with

- HTML5
- CSS3 (custom properties, grid, flexbox, animations)
- JavaScript (no frameworks or libraries)

## Run it locally

1. Download or clone this repository:
```bash
   git clone https://github.com/afrasyabkhan76-debug/REPOSITORY-NAME.git
```
2. Open the folder in VS Code.
3. Open `index.html` in your browser, or use the **Live Server** extension for automatic refresh.

No installation is needed.

## Customise

- **Text and links:** edit `index.html`.
- **Colours:** change the values at the top of `style.css` (the `:root` section).
- **Typing roles:** edit the `roles` list in `script.js`.
- **Photo:** replace the image in the `assets` folder and keep the same file name.
